# Remote Box - 2D Web 遥控差速底盘

通过手机网页二维摇杆控制 ESP32-S3 差速驱动底盘。

**无 UWB、无 IMU**，仅依赖：底盘 (APO-DL ESC + 编码器 PID) + web_control 组件 + ESP32-S3 开发板。

---

## 一、硬件连接

### 1. ESP32-S3 到 APO-DL 控制信号

APO-DL 每个通道有一组 `- + S` 信号接口：
- `S` = 信号输入（接 ESP32 GPIO）
- `-` = 信号地（接 ESP32 GND）
- `+` = **不接 ESP32**

| ESP32-S3 | APO-DL |
|----------|--------|
| GPIO4 | A 通道 S（左电机） |
| GPIO5 | B 通道 S（右电机） |
| GND | A 通道 - |
| GND | B 通道 - |
| **不接** | A/B 通道 + |

> ⚠️ APO-DL 的 `+` 信号针不要接 ESP32。

### 2. 电机动力线

电机蓝线和白线接到 APO-DL 的 MOTOR 输出端：

| 电机 | APO-DL |
|------|--------|
| 左电机蓝线/白线 | A 通道 MOTOR 两个端子 |
| 右电机蓝线/白线 | B 通道 MOTOR 两个端子 |

如果左右轮方向相反，把其中一个电机的蓝线和白线对调即可。**本项目默认不进行软件反向**，方向由硬件接线处理。

### 3. 电池电源

6S 电池**只接** APO-DL 主电源输入，**不要接 ESP32**。

| 电池 | APO-DL |
|------|--------|
| 6S 正极 + | 主电源 + |
| 6S 负极 - | 主电源 - |

> 建议在电池正极和 APO-DL 之间串联保险丝和急停开关。

### 4. 编码器连接

编码器线用于读取轮子转动计数，不影响电机转动。

**左电机编码器：**

| 编码器线颜色 | ESP32-S3 |
|-------------|----------|
| 绿线 | 3V3 |
| 黄线 | GND |
| 黑线 | GPIO6（A相） |
| 红线 | GPIO7（B相） |

**右电机编码器：**

| 编码器线颜色 | ESP32-S3 |
|-------------|----------|
| 绿线 | 3V3 |
| 黄线 | GND |
| 黑线 | GPIO15（A相） |
| 红线 | GPIO16（B相） |

> 如果编码器线色与实际电机不一致，需根据电机说明重新确认。

### 5. 共地要求

ESP32-S3 和 APO-DL **必须共地**：

- ESP32 GND
- APO-DL A 通道 -
- APO-DL B 通道 -
- 编码器黄线 GND

这些地线需要连接在一起。不共地会导致 APO-DL 无法正确识别控制信号。

## 二、APO-DL 模式设置

本项目使用 RC 航模电调信号：
- 频率：50Hz
- 停止中点：1500µs
- 正向最大：2000µs
- 反向最大：1000µs

**APO-DL 需要设置为 RC 航模信号模式，并关闭混控**，使 A/B 两通道独立工作。

### 中点校准

如果 APO-DL 通电后轮子自己转，需要重新校准：

1. ESP32 先上电并运行程序（输出 1500µs 停止信号）
2. APO-DL 上电
3. 按下 APO-DL 中点校准按钮
4. 按说明完成第二次确认
5. 电机停止后开始测试

校准成功后：ESP32 输出 1500µs 时电机应保持停止，不应明显发热。

## 四、网页使用方法

### 1. 连接 WiFi

ESP32 上电后创建热点：
- SSID: `RemoteBox`
- 密码: `12345678`

### 2. 打开控制页面

浏览器访问 `http://192.168.4.1`

### 3. 解锁电机

页面加载后电机处于 **E-STOP 状态**，点击 **CLEAR/ARM** 解锁。

> 每次 CLEAR/ARM 生成新 session，旧命令帧无效。

### 4. 遥控操作

```
      [ ▲ 前进 ]
[ ◀ 左转 ] [ STOP ] [ ▶ 右转 ]
      [ ▼ 后退 ]
```

**操作方式：**

- **持续按住**"前进" → 直行（不是点击）
- **持续按住**"左转" → 原地左转
- **双指同时按住**"前进"+"左转" → 左弧前进
- **同轴冲突**（前进+后退）→ 自动抵消归零

支持多指触控，手机同时按两个按钮可正确组合。

### 5. 速度调节

页面下方 **Speed 滑块**（20%–100%）控制全局速度倍率。

### 6. 紧急停车

- 点击红色 **STOP** 按钮
- 断开 WiFi
- 关闭浏览器页面（自动发送 zero 命令）
- 切后台/锁屏（自动发送 zero 命令）

### 7. 关闭运动

点击 **MOT OFF** 取消运动授权（保留连接和数据采集）。

### 8. 下载日志

点击 **CSV** 链接下载 Flash 遥测日志。

## 五、控制逻辑

```
手机按钮事件
    ↓
浏览器本地状态机（多指触控处理）
    ↓
POST /cmd { x, y, scale, deadman, session, seq }  ← 20Hz + 变化时立即发
    ↓
ESP: 验证 session/seq → 存入 remote_cmd 缓冲区
    ↓
control_task 50Hz:
    1. E-stop 快速路径 → chassis_stop()
    2. 读取 remote_cmd
    3. 安全仲裁（estop → disconnect → timeout → disarmed → wait_zero → deadman → valid）
    4. expo(apply_deadband(x/y)) → v/omega
    5. 弯道降速
    6. ramp 限速
    7. chassis_set_velocity() + chassis_update()
```

### x/y → v/omega 映射

| 按键 | x | y | 运动 |
|------|---|---|------|
| 前进 | 0 | +1 | 直行 |
| 后退 | 0 | -1 | 倒车 |
| 左转 | +1 | 0 | 原地左转 |
| 右转 | -1 | 0 | 原地右转 |
| 前进+左转 | +1 | +1 | 左弧前进 |
| 前进+右转 | -1 | +1 | 右弧前进 |

**低速优化：**
- Deadband: 5% 以内输入归零防抖
- Expo: `x × |x|`，低速细腻高速保留
- 弯道降速: 转弯时自动降低前进速度

## 六、安全机制

| 保护 | 行为 |
|------|------|
| E-STOP 按钮 | 锁存停车，需重新 CLEAR/ARM |
| WiFi 断连 | 自动锁存 E-STOP |
| Heartbeat 超时 (1.5s) | 自动锁存 E-STOP |
| 命令超时 (500ms) | 目标速度归零 |
| Deadman 松开 | 目标速度归零 |
| 未 ARM | 所有运动禁止 |
| ARM 后未回零 | 等待零命令后才允许运动 |

**仲裁优先级：** ESTOP > DISCONNECT > TIMEOUT > DISARMED > WAIT_ZERO > CMD_TIMEOUT > DEADMAN_OFF > VALID

## 七、标定步骤

1. **垫高轮子空跑**：确认电调解锁（上电后等待2秒ESC自检）
2. **确认方向**：网页点前进，轮子应向前转；如果反了，在 menuconfig 中开启对应 `Invert` 选项
3. **标定编码器**：手推恰好1米，看日志中 tick delta，修改 `TICKS_PER_METER`
4. **低速测试**：Speed 滑块拉到 20%，点前进，观察 `meas L/R` 是否跟随 `tgt L/R`
5. **转向测试**：同时按住前进+左转，确认左弧运动
6. **停车测试**：按住前进时点 STOP，确认立即停车
